# RFC-0001: superseded product experiment

Status: superseded.

This filename is retained so existing links do not break. The earlier experiment framed the repository as a vertical-specific delivery workflow. That scope no longer matches the open-source project.

The adopted product is **Video Evidence Workbench**: an open-source, local-first, auditable shot-level video research workbench. Ad analysis is one profile alongside festival, short-form, and streaming analysis.

## Adopted lessons

- `shot/frame` remains the primary review unit;
- storyboard and shot table remain high-value human outputs;
- readiness must fail closed when evidence is incomplete;
- deterministic extraction and model annotation must remain separate;
- source-to-shot lineage is useful when it is grounded in files and timecodes;
- one complete short-video workflow is more valuable than speculative platform breadth.

## Rejected assumptions

- vertical-specific service language as the project identity;
- account, order, or checkout surfaces before a reliable local evidence loop;
- a generic chat panel as the primary interface;
- simulated provider or generation results presented as product behavior;
- an infinite creative canvas as the default shot-review experience.
